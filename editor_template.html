Baddi Boundary Editor Town / Ward / Block / IV digitizing — QGIS-compatible

Boundary Layers

Select a layer below, then use the draw tools on the map (top-left) to add a new boundary of that type. New shapes ask for attributes before saving.

Editing

Toggle a mode, use it on the map, then click the same button again to stop. Cut and Remove work on any visible layer; Edit/Drag only affect the active layer.

Project prefix

Used to name exported files, e.g. Baddi_ward_boundary.shp

Data check

Run a check before exporting to catch blocks referencing a ward/IV number that doesn't exist yet.
